Plot autoscales to the frame peak, so every bin from avg (~140) up to max (~240) crowds the top half. The WiFi carrier sits as a wall of green with jittery peaks; quiet vs. busy bins look nearly the same height.
A + B — floor subtract + avg overlay
plot: (v − WF_Floor) × WF_Gain  |  cyan = slow EMA per bin
live trace peak-hold avg (per-bin EMA)
Quiet bins hug the baseline; busy bins reach the top. The cyan line shows the per-bin average so you can see where the floor sits and how far the live trace rises above it.
SDR — calibrated dBm + 3-trace
y-axis: Ref −30 .. −100 dBm  |  10 dB grid  |  peak marker
live avg max-hold peak marker
GQRX / SDR# convention: dBm Y-axis with Ref Level at the top and Range below. 10 dB grid lines labeled on the left. Three traces at once: live (green), per-bin average (cyan = noise floor), max-hold ridge (amber). Peak marker in the corner reads out dBm + MHz. Waterfall color scale is pinned to the same dB range so vertical color = calibrated signal strength.
