Signalhound S3 — same tool, more room, two modes

The S3 variant of the Signalhound build. Everything the Classic does, plus second-long bursts in PSRAM, SIMD-accelerated decoders that make OFDM realistic, parallel decode lanes, and a native-USB tethered mode that turns the device into a SoapyESPSDR source for a PC when plugged in — standalone when unplugged.

Core-0 · RF Core-1 · UI + decode SIMD · vector path

▸ What the S3 changes vs Classic

  • Burst stage moves from internal SRAM (~400 KB) to PSRAM (8 MB typical) 10 ms → ~2 s
  • Vector math (PIE) accelerates FFT, FIR, correlators, Viterbi ~4× decode
  • Realtime WiFi OFDM demod becomes borderline-feasible on a decimated 10 MHz slice decode in-session
  • Native USB-OTG CDC → device acts as a SoapyESPSDR source when tethered new mode
  • Larger flash / RAM → multiple decoders resident at once, one per core parallel lanes
  • If the S3 CYD has 4-bit SDMMC pads, SD write bandwidth jumps ~5× continuous wideband

Dual-core architecture (S3)

Same split as Classic, with PSRAM between Core-0 and Core-1 so bursts are measured in seconds rather than milliseconds, and SIMD lanes on both cores so decoders don't block the UI.

Feature list

Everything from Classic still applies; this list highlights what S3 adds or changes. New cards are marked.

▸ NEW · PSRAM burst stage

  • C0 PSRAM Burst up to 2 seconds @ 20 MS/s complex (80 MB)
  • C0 PSRAM Decimated continuous capture of minutes at narrower rates
  • C0 Pre-trigger buffer up to 500 ms, not 2 ms
  • C1 Drain-to-SD happens in background; radio stays alive

▸ NEW · SIMD-accelerated decoders

  • SIMD ~4× speedup on FFT, FIR, correlators, Viterbi butterflies
  • C0SIMD Lane A runs realtime demod of narrow protocols
  • C1SIMD Lane B runs wider / offline jobs including OFDM
  • Both lanes run in parallel when the radio isn't demanding

▸ NEW · Decoder bank

  • C1 Multiple decoders resident in RAM simultaneously
  • C1 Explicit lane routing per decoder (A/B/either)
  • C1 Load/unload from SD without reboot
  • Decoded frame types: OFDM a/g/n, 802.11b DSSS, BLE 1M/2M, NRF24, 802.15.4, LoRa 2.4

▸ NEW · Tethered mode (USB)

  • C1USB Device enumerates as native USB CDC when plugged in
  • C0USB Streams decimated I/Q at up to 250 kSa/s (ESP-SDR S3 upstream protocol)
  • Works with esp-sdr-bridge → SpyServer / rtl_tcp
  • Compatible with Gqrx, SDR++, SDR#, GNU Radio
  • Falls back to standalone when unplugged; no mode-switch required

▸ RF capture (same, faster)

  • C0SIMD Live FFT ~90 Hz (vs ~60 Hz on Classic)
  • C0 Full 2402–2482 MHz sweep + retune, 1 MHz grain
  • C0 Peak hold, averaging ×2–×16, min-hold
  • C0 Hardware AGC, manual gain index

▸ Classification (same, more types)

  • C0SIMD OFDM / FHSS / CW / chirp shape detector
  • C0 Jammer / microwave / drone-uplink badges
  • C0 Live BLE 1M vs 2M distinguisher
  • C0 Zigbee channel-energy pie (11–26)

▸ Storage (same, bigger)

  • C1 SD write to /caps/*.iq at MB/s scale
  • C1 Session log /sessions/*.jsonl with classifier output
  • C1 Decoded findings /findings/*.jsonl
  • C1 SigMF export, SoapyESPSDR snapshot recording

▸ Operator UX (same)

  • C1 Nine screens — HOME grows to 8 tiles with BANK + TETHER
  • C1 Dirty-rect redraw; faster thanks to vector blit on S3
  • C1 Tap-tune in LIVE, one-tap REC = 2 s burst
  • C1 Progress badges on CAPTURES rows, parallel-lane view
